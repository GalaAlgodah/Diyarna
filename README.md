
# Diyarna | ديارنا 🇸🇦

## About the Project

**Diyarna (ديارنا)** is an interactive cultural website designed to introduce users to the rich heritage and traditions of different regions of Saudi Arabia.

The project provides an engaging way to explore Saudi culture through an interactive map. Users can select a region and discover its traditional food, clothing, landmarks, coffee culture, and folk arts.

## The Problem

Saudi Arabia has a rich and diverse cultural heritage, with each region having its own traditions, food, clothing, landmarks, and arts.

However, cultural information is often distributed across different sources and presented in traditional formats that may not provide an interactive and engaging experience.

**Diyarna** brings this information together in one visual and interactive digital platform.

## Project Goal 🎯

The goal of **Diyarna** is to create an interactive digital platform that presents the cultural identity of Saudi regions in a simple, attractive, and engaging way.

The project also aims to combine Saudi heritage with modern technology and AI-assisted development to make exploring local culture more enjoyable and accessible.

## Main Features ✨

- 🗺️ **Interactive Saudi Arabia Map** – Users can explore regions directly through the map.
- 🏛️ **Regional Pages** – Each selected region has its own dedicated page.
- 🍽️ **Traditional Food** – Discover famous traditional dishes from each region.
- 👗 **Traditional Clothing** – Explore traditional clothing and regional styles.
- 🏺 **Heritage & Landmarks** – Learn about important historical and cultural landmarks.
- ☕ **Coffee Culture** – Discover coffee traditions in different regions.
- 🎭 **Folk Arts** – Explore traditional arts and cultural practices.
- 🌐 **Arabic & English Support** – The website supports both Arabic and English.
- 🧊 **3D & Interactive Design** – Interactive and 3D visual elements create a modern cultural experience.

## How Diyarna Works 🔎

1. The user enters the Diyarna website.
2. An interactive map of Saudi Arabia is displayed.
3. The user selects a region from the map.
4. The website opens the selected region's page.
5. The user can explore its food, clothing, landmarks, coffee culture, and folk arts.
